# unyform-ai/homebrew-tap

Homebrew formulae for [MechCrate](https://mechcrate.dev).

```bash
brew install unyform-ai/tap/mechcrate
```

`Formula/mechcrate.rb` is generated by `scripts/homebrew/render-formula.sh` in
[Dev916/mech-crate](https://github.com/Dev916/mech-crate) from the checksum
sidecars of each stable release on
[unyform-ai/mech-crate-releases](https://github.com/unyform-ai/mech-crate-releases).
The `tap-bump` job in that repo's release workflow opens a pull request here
for every new version; do not edit the formula by hand.
